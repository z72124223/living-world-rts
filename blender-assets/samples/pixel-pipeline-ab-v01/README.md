# 女性輕甲：2D / 3D 像素比較

2026-09-06。兩個版本都參考已認可女性概念圖中央的輕甲角色。本輪為靜態外觀比較，尚未獲得使用者美術認可，也不代表動畫量產流程通過。

- `compare.html`：並排比較，可切換 128 / 256 預覽、原尺寸 / 放大，以及 3D 斜側面 / 正面 / 背面。以瀏覽器開啟，或由本機靜態伺服器提供。
- `2d-direct.png`：透過內建圖片生成工具，使用概念圖作為參考直接生成的 2D 像素風格原圖。沒有經過逐格動畫、分層換裝或嚴格像素網格驗收。完整提示詞保存在 `2d-generation-prompt.txt`。
- `3d-pixel-source.blend`：從既有實際模型另存的新修訂，重新調整身形、臉部特徵與分階配色。各幾何零件分開保留；使用原始模型的姿勢烘焙成靜態網格，本版不含可用動畫骨架。
- `3d-pixel-256.png`、`3d-pixel-128.png`：實際 Blender 原生解析度渲染；沒有生成式重繪或概念圖投影。
- `3d-front-256.png`、`3d-back-256.png`：同一模型的另外兩個方向。
- `3d-build-report.json`：来源與生成資訊。

比較頁對 2D 原圖使用最近鄰縮放至共同預覽尺寸，並保留原檔。這是方便判斷畫面的顯示設定，不能把生成原圖宣稱為原生 128 像素逐格繪製。

3D 仍有造型差距，衣甲沒有完成動畫綁定；本輪沒有測試 Godot 執行效能。既有 v01 模型與來源授權檔均保留不動。

重建 3D：在專案根目錄執行 Blender 背景模式，參數為 `--factory-startup --python-exit-code 1 --python scripts/build_pixel_ab_3d.py`。
