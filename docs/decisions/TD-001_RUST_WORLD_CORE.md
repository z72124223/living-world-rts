# TD-001：MP0 世界模擬核心採 Rust

狀態：已決議
日期：2026-08-08
更新：2026-09-06；客戶端選型依 TD-002 更新，Rust 核心決策不變。

## 決策

MP0 的世界／模擬核心採用 Rust。

Rust 負責目前與未來可逐步擴充的權威世界規則，例如人物、組織樹、指揮鏈，以及後續可能加入的戰鬥、軍事通訊、經濟、事件與歷史等領域邏輯。

## 客戶端與尚未鎖定事項

- 遊戲客戶端引擎：Godot，依 [TD-002](TD-002_GODOT_BLENDER_ART_PIPELINE.md)；資產製作採 Blender。
- Rust 與 Godot 的介接方式：待最小接合驗證，尚未實作。
- 資料庫：未定；MP0 優先允許純記憶體模型。
- 網路協定：未定。
- 部署／雲端平台：未定。

## 理由

1. 世界核心需要與客戶端呈現層解耦，避免未來更換 Unity、Godot 或其他客戶端時重寫核心世界規則。
2. 長期方向包含大量人物／部隊狀態、持續世界與多人權威模擬，Rust 適合作為高效、可控的伺服器／模擬核心。
3. MP0 仍以最小可執行骨架為優先，不因選擇 Rust 就提前加入資料庫、Redis、微服務、容器編排等非必要基礎設施。

## MP0 技術邊界

第一版只需建立可建置、可測試的 Rust 專案，並完成 `MP0-001` 人物核心模型。後續功能必須以 Issue 漸進加入。
