《異域》登入與創建角色　本機版本

開發中：目前提供登入與創角流程測試，先前談定內容尚未全部實裝。
測試目前流程：請雙擊「測試創建角色.cmd」，保留整個資料夾。
登入頁 → 開始創角測試 → 模擬實名查核 → 模擬智慧服務 → 首次傳送或隨機投胎。
測試全部使用虛構資料，無須證件、帳號密碼或 API 金鑰，不呼叫付費服務。
測試身分固定女性，不能選性別或外貌。投胎沿用父母取好的姓名與子女既有外貌。
本次新增：選擇「隨機投胎」時先顯示等待配對；確認入世後顯示聚落子女的人物圖。
首次傳送仍穿現代衣服；返回登入再進入創角，會保留已接手子女的模樣。
畫面會持續標示測試；「重新測試」可重開一輪，關閉遊戲即清除本輪資料。
測試資料無法轉為正式角色，不代表通過真正的實名或 OpenAI 查核。
公開子女名單為虛構資料；其他玩家家庭、出生取名與公開／保留操作尚未接入。
創角後目前停在登記結果，尚未接入可遊玩的世界。

正式本機帳號模式：雙擊「啟動異域.cmd」。
登入遊戲 → 建立／登入帳號 → 實名查核 → 智慧服務 → 創建角色。
上方四個頁籤都能查看；未通過必要查核時，確認入世會停用。
外貌不能選擇；登記性別由實名服務確認。初始只有現代服裝。

目前 Persona 尚未申請／設定，所以正式實名查核尚未開放。
畫面不會假裝驗證成功。只有正式查核及 OpenAI 連線、姓名審核均通過才能保存角色。
這個版本不會進入舊營地，不包含戰鬥或死亡後選角。

帳號與加密金鑰保存在本機 Windows 使用者的：
%LOCALAPPDATA%\Yiyu\registration
API 金鑰由玩家自備，請不要提供給 AI 對話或其他玩家。
每日遊戲 AI 請求次數是使用量限制，不是金額保證；以 OpenAI 帳單為準。

營運方未來可使用 service\設定實名服務.ps1 設定 Persona。
正式營運需要營運方控制的中央 HTTPS 後端；本機資料庫不是線上反作弊權威。
這是本機可操作版本，尚未部署公開服務。
